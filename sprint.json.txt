3. Порядок выполнения
Register User - создать пользователя

Login User - получить токены (автоматически устанавливаются)

Create Workspace - создать рабочее пространство

Create Task - создать задачу

Далее можно тестировать остальные эндпоинты

4. Особенности коллекции
Автоматическое сохранение ID - workspaceId и taskId сохраняются автоматически

Тесты для автоматизации - автоматически устанавливают токены и ID

Полное покрытие API - все эндпоинты задокументированы

Примеры данных - реалистичные примеры запросов и ответов

Организация по папкам - логическая группировка функциональности
